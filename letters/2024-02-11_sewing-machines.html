Using Pappy's machine again.................

There are four sewing machines here -- I'll attach pictures. The black
machine (a Precision model) on the cedar table by the window is the one
Momma was using the last years (I don't remember how long) before she could
no longer remember how. It was in working order, but she did fidget with
it a lot when she sometimes could & couldn't remember how to use it those
last few years. The other black one, in the pantry, is a very similar
machine & it may have been partially cannibalized for parts. The more
modern off-white (Singer Futura II) was used for a while but got put in the
pantry sometime and I don't remember when or why. The ol;d singer in the
cabinet was purchased sometime around 2010 (I think that's when) for a
project for Momma to fix up, and she & Pappy did work on it a bit. It's a
treadle machine and does work; the cabinet needs re-finishing I think.

Does anyone want any of these machines?

Does anyone want any of her patterns?

Does anyone want any of her fabric that is NOT suitable for quilting?
There's fake fur in various colors, there's a lot of stretchy stuff, etc.
I plan on using any that is suitable for quilting in some memory quilts.

Please be sure any answers include me so I can keep track.
Elizabeth Diane
